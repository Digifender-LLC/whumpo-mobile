# Whumpo rhino on Android

The original Whumpo rhino vector is the source for both the Compose mascot and the launcher icon. The decorative mascot retains its existing size and accessibility behavior. Slate and muted teal are used on light surfaces, with ivory and teal on dark surfaces.

The launcher sets the simplified silhouette inside the adaptive icon safe zone. The rounded and standard launchers use the same foreground. The launcher omits the small eye to keep the silhouette legible. The silhouette also supplies the monochrome launcher mask.

The SVGs in this directory are the original artwork. Historical store listings and reference material document previous builds.
