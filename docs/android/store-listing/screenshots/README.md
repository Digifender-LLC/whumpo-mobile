# Store listing screenshots

Generated by the Roborazzi harness (`storeListing` tests in `ScreensScreenshotTest` and `ChatScreenshotTest`, helper `captureStore` in `RobolectricSupport.kt`), with the same synthetic fixtures as the other goldens (Example Detailing, Corner Bakery orders, Garden club newsletter; `example.test` addresses). No real data. Local host tests compare these baselines; this import does not install CI. To intentionally re-record, run `./gradlew :shared:testAndroidHostTest -Pscreenshots.record=true --rerun-tasks` from `android/` and review the changed images before committing. These assets are not evidence of Play publication.

| Folder | Pixels | Use in Play Console |
| --- | --- | --- |
| `phone/` | 1080 x 1920 | Phone screenshots |
| `tablet7/` | 1200 x 1920 | 7-inch tablet screenshots |
| `tablet10/` | 1600 x 2560 | 10-inch tablet screenshots |

Each name ends in `-light` or `-dark`. Phone: `1-chat`, `2-projects`, `3-project-detail`, `4-activity`. Tablets: `1-chat`, `2-project-detail` (the projects list and Activity are short single columns below 840 dp and would leave most of a tablet frame empty).

Play wants 2 to 8 screenshots per device type; upload the light set or the dark set (or a mix). The frames are the app content only, with no device bezel, status bar or navigation bar. Tablet frames are portrait.

Known gaps: the screens are the stateless content composables, so the bottom navigation bar is not drawn; a framed marketing version with captions is a design task. The Activity "A change is ready for your review" banner is left out because its **Dismiss** label has low contrast in dark mode (a UI bug to fix separately).
